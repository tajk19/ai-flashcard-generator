# AI Flashcard Generator

Версия 0.3.4: единый пакет для настольного и мобильного Obsidian. Ошибки Gemini теперь показывают безопасный машинный код и HTTP-статус, не раскрывая текст заметки, промпт или ключ. См. [установку по платформам](docs/INSTALLATION.md), [аудит безопасности](docs/SECURITY-AUDIT.md) и [публикацию](docs/PUBLISHING.md). Подробности актуальной версии также есть в [English README](README.md).

Небольшой плагин поверх [Spaced Repetition](https://github.com/st3v3nmw/obsidian-spaced-repetition): он превращает выделение или текущую заметку в проверяемый набор карточек Gemini, показывает обязательный предпросмотр и только после подтверждения создаёт отдельную Markdown-колоду. Алгоритмов интервального повторения в плагине нет.

## Возможности

- Команда `Generate flashcards from current note` всегда видна в палитре; если Markdown-заметка не открыта, плагин показывает понятное уведомление.
- Единое многоэтапное окно: настройка, отменяемая генерация, предпросмотр и сохранение.
- Непустое выделение имеет приоритет; иначе используется актуальный текст всего редактора, включая ещё не сохранённые изменения.
- Перед запросом показываются выбранный источник, его объём и предполагаемый итоговый путь.
- Встроенный профиль `Atomic notes` для атомарных карточек строго по конспекту.
- Встроенный профиль `English vocabulary and phrases`: одна пара `English ↔ перевод` сохраняется как нативная двусторонняя карточка Spaced Repetition.
- Профиль `Custom prompt` с сохраняемыми пользовательскими инструкциями.
- Переменные `{{count}}` и `{{targetLanguage}}` в пользовательском промпте.
- Стабильная модель `gemini-3.1-flash-lite` по умолчанию.
- Structured output `question + answer + evidence` с локальной проверкой смысла поверх проверки формы JSON.
- Редактируемый предпросмотр с выбором карточек и метками качества: `Supported`, `Not grounded`, `Duplicate`, `Conflict`, `Too long`, `Edited`.
- Сохранение только явно выбранных карточек; цитата-основание нужна для проверки и в Markdown не попадает.
- Автоматическое чтение разделителей однострочных basic (`::`) и bidirectional (`:::`) карточек из настроек Spaced Repetition; ручной режим остаётся резервным.
- Точный пользовательский deck tag без принудительного префикса `flashcards/`.
- Создание отдельной колоды в папке `Flashcards`.
- Ссылка на исходную заметку.
- Пользовательское имя файла, предварительная проверка пути и уникальные суффиксы `(2)`, `(3)` без перезаписи.
- Повторная проверка свободного имени непосредственно при записи защищает от файловых гонок.
- Нейтрализация неожиданных deck-тегов, raw HTML и Markdown-embed внутри ответа модели.
- API-ключ через Obsidian Secret Storage: в `data.json` хранится только ID выбранного секрета.
- Работа на desktop и mobile без Node.js API во время выполнения.

Версия `0.3.4` создаёт новые basic Q&A-колоды для конспектов и двусторонние колоды для встроенного английского профиля. Append в существующую колоду, cloze и поиск дублей по всему vault в этот релиз не входят.

## Профили промптов

`Atomic notes` извлекает только явно указанные в заметке факты, сохраняет язык источника и формирует атомарные вопросы. Это профиль по умолчанию.

`English vocabulary and phrases` выбирает встречающиеся в заметке английские слова, phrasal verbs, collocations, idioms и короткие фразы. Модель возвращает одну пару: английскую единицу в `question` и контекстно подходящий перевод в `answer`. Плагин записывает её через reversed-разделитель Spaced Repetition, обычно `:::`, поэтому одна строка даёт оба направления: `EN → перевод` и `перевод → EN`. Отдельную перевёрнутую JSON-карточку модель создавать не должна. Перевод может отсутствовать в исходном тексте — для этого профиля он является разрешённым преобразованием, а не выдуманным фактом.

`Custom prompt` позволяет описать собственные правила отбора и формулировки карточек. Исходный текст добавлять в промпт не нужно: плагин прикрепляет его автоматически после защищённого маркера. Формат результата остаётся структурой `question + answer + evidence`, а в колоду записываются только вопрос и ответ.

В 0.3 доступны два встроенных профиля и один сохраняемый пользовательский промпт. Библиотека нескольких именованных пользовательских профилей запланирована на 0.4.

## Требования

- Obsidian `1.13.0` или новее.
- Включённый community plugin Spaced Repetition.
- Gemini auth key из [Google AI Studio](https://aistudio.google.com/).
- Node.js 22.12+ только для локальной сборки.

## Сборка и установка

Плагин опубликован в официальном каталоге Obsidian Community plugins. Для обычной установки найдите `AI Flashcard Generator` в настройках Community plugins. Ручная установка ниже остаётся полезной для тестовой версии или восстановления.

В каталоге проекта:

```bash
npm install
npm run build
```

Затем скопируйте каталог в:

```text
<VAULT>/.obsidian/plugins/ai-flashcard-generator/
```

Для запуска достаточно этих файлов:

```text
main.js
manifest.json
styles.css
```

Перезапустите Obsidian или выполните `Reload app without saving`, затем включите `AI Flashcard Generator` в разделе Community plugins.

Для разработки с автоматической пересборкой:

```bash
npm run dev
```

## Настройка

Откройте `Settings → Community plugins → AI Flashcard Generator`:

1. В `Gemini API key` выберите существующий секрет или создайте новый.
2. Оставьте модель `gemini-3.1-flash-lite` либо укажите другой совместимый model ID.
3. Выберите профиль промпта по умолчанию. Текст встроенного профиля можно раскрыть прямо в настройках.
4. Для английских карточек укажите язык перевода, например `Russian`.
5. Для `Custom prompt` вставьте свои инструкции. Доступны `{{count}}` и `{{targetLanguage}}`; заметка добавляется отдельно автоматически.
6. Выберите максимальное число карточек; для английского профиля это число двусторонних пар.
7. Укажите папку и точный тег колоды. Оставьте `Sync card separators` включённым: плагин прочитает basic- и bidirectional-разделители из Spaced Repetition. При необходимости отключите синхронизацию и задайте оба буквальных значения вручную.
8. При желании отключите автоматическое открытие созданного файла.

## Использование

1. Откройте Markdown-конспект и при необходимости выделите только нужный фрагмент.
2. Нажмите `Ctrl+P`.
3. Запустите `AI Flashcard Generator: Generate flashcards from current note`.
4. Проверьте источник, его объём, профиль, лимит, папку, тег, найденные разделители и имя будущего файла. Предполагаемый суффикс при коллизии уже будет показан в пути.
5. Нажмите `Generate`.
6. Проверьте карточки: отредактируйте формулировки, раскройте evidence и оставьте флажки только у нужных элементов. `Select valid` выбирает карточки без критических предупреждений, `Clear selection` снимает выбор, а `Regenerate` повторяет запрос.
7. Нажмите `Create N cards`; для английского профиля кнопка называется `Create N bidirectional pairs`. Только теперь плагин создаст файл.

```text
Flashcards/C++ unique pointers.md
```

Расширение `.md` в поле имени указывать необязательно. Если файл уже существует, плагин создаст `C++ unique pointers (2).md`, не перезаписывая прежнюю колоду.

Содержимое:

```markdown
# C++ unique pointers

#flashcards/generated

<!-- AI Flashcard Generator source --> Source: [[std unique_ptr]]

## Flashcards

Что обеспечивает std&#58;&#58;unique_ptr?::Уникальное владение объектом.

Можно ли копировать std&#58;&#58;unique_ptr?::Нет.
```

`&#58;&#58;` отображается в Obsidian как `::`. Такое кодирование нужно, потому что Spaced Repetition делит однострочную карточку по первому буквальному `::`; иначе C++-имя `std::unique_ptr` ошибочно стало бы разделителем.

Английская пара сохраняется одной строкой:

```markdown
break the ice:::разрядить обстановку
```

Spaced Repetition создаёт из неё два направления повторения. Плагин также экранирует внутри содержимого оба найденных inline-разделителя, поэтому, например, `std::move` не перехватит разбор строки с активным `:::`.

Потенциально активный Markdown из ответа модели безопасно сериализуется: дополнительные deck-теги экранируются, raw HTML показывается как текст, а image/embed-конструкции не загружаются автоматически. Обычный текст, выделение и inline code сохраняются.

Строка источника начинается со служебного HTML-комментария: он скрыт при чтении, ссылка остаётся видимой, а парсер Spaced Repetition гарантированно пропускает всю эту строку даже тогда, когда путь заметки содержит пользовательский разделитель.

Если Gemini не нашёл подходящих фактов, пользователь отменил или закрыл окно либо не выбрал ни одной карточки, файл не создаётся. Поздний ответ API после отмены или выгрузки плагина игнорируется. Уже отправленный Google запрос при этом может завершиться и учитываться в квоте.

## Проверка качества

Gemini должен вернуть для каждой карточки короткую дословную цитату `evidence`. Плагин нормализует Unicode в форму NFKC, регистр и пробелы, а затем ищет цитату в отправленном источнике. Для английского профиля дополнительно проверяется присутствие исходного английского слова или выражения.

- Найденная цитата получает `Supported` и выбирается по умолчанию.
- Ненайденная цитата получает `Not grounded` и по умолчанию не выбирается.
- У точных повторов выбранным остаётся только первый; остальные получают `Duplicate`.
- Карточки с одинаковым вопросом и разными ответами получают `Conflict` и снимаются все.
- Вопрос длиннее 300 символов или ответ длиннее 500 символов получает `Too long`, но остаётся доступным для осознанного выбора.
- После ручного изменения вопроса или ответа появляется `Edited`.

Флажки у предупреждений остаются доступны: пользователь может явно подтвердить исключение. `evidence` служит только для принятия решения в предпросмотре и никогда не записывается в колоду.

## Лимиты и отмена

Плагин ничего не обрезает молча:

- исходный текст — не более 100 000 символов;
- пользовательский промпт — не более 8 000 символов;
- JSON-ответ — не более 1 MiB;
- каждое поле `question`, `answer` и `evidence` — не более 2 000 символов;
- Gemini `max_output_tokens` — 8192.

Если источник слишком велик, выделите меньший фрагмент заметки. Генерацию можно отменить; закрытие окна или выгрузка плагина также запрещает позднему ответу создавать файл. После подтверждения сохранения и начала `vault.create` закрытие окна уже не может отменить эту запись.

## Приватность

Текст текущей заметки и выбранные инструкции промпта отправляются напрямую с устройства на `generativelanguage.googleapis.com`. Пользовательский промпт может содержать чувствительные данные, поэтому к нему относится то же предупреждение. Плагин не содержит телеметрии и передаёт `store: false`, но это не отменяет политику Gemini Free Tier: Google указывает, что данные бесплатного тарифа могут использоваться для улучшения продуктов. Не отправляйте через Free Tier приватные или чувствительные заметки.

На 29 августа 2026 года входные и выходные токены `gemini-3.1-flash-lite` в Standard Free Tier указаны как бесплатные, однако тарифы и лимиты могут меняться. Проверяйте актуальные условия на странице [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing).

## Почему Interactions API

Новая интеграция использует рекомендованный Google Interactions API:

```text
POST https://generativelanguage.googleapis.com/v1beta/interactions
```

Запрос включает `response_format` с JSON Schema, `thinking_level: minimal`, `max_output_tokens: 8192` и `store: false`. Structured output гарантирует форму ответа, но не достоверность содержимого, поэтому плагин отдельно проверяет типы, размеры полей и evidence.

## Дальнейшие версии

- **0.4:** библиотека именованных профилей со своими промптом, языком, лимитом, папкой и тегом; выбор только одного направления либо обоих; безопасный append без изменения `<!--SR:...-->`.
- **0.5:** типизированные basic и cloze-карточки и расширяемые правила выбора формата.

Плагин не планирует собственное расписание, статистику, массовую генерацию по всему vault, OCR или автоматическую перезапись уже изучаемых карточек: эти задачи либо принадлежат Spaced Repetition, либо слишком рискованны для автоматического режима.

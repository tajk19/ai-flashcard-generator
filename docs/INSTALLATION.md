# Установка 0.3.4: Linux, Windows и телефон

Используется один и тот же пакет: `main.js`, `manifest.json`, `styles.css`. Отдельных APK, DEB или EXE у плагина нет. Нужен Obsidian 1.13.0+ и включённый Spaced Repetition на каждом устройстве.

## Linux / Windows / macOS

1. Сохраните текущие изменения в Obsidian. При обновлении отключите AI Flashcard Generator.
2. Откройте папку вашего vault и включите показ скрытых файлов (в большинстве файловых менеджеров Linux — Ctrl+H).
3. В каталоге конфигурации vault, обычно `.obsidian`, откройте `plugins/ai-flashcard-generator/`. Создайте папку, если её нет.
4. Поместите туда три файла из установочного ZIP. Избегайте двойной вложенности `ai-flashcard-generator/ai-flashcard-generator`.
5. Сохраните существующий `data.json` при обновлении. Перезапустите Obsidian и включите плагин в Community plugins.
6. В настройках выберите Gemini secret. Откройте заметку и запустите команду из палитры либо кнопкой с иконкой слоёв на ленте.

Не нужны root/sudo, глобальный npm или отдельный сервис. Для Flatpak/AppImage используется та папка vault, которая доступна самому Obsidian. Названия каталогов и импортов в исходниках учитывают регистр Linux. Слишком длинное имя с Unicode отклоняется до запроса Gemini.

## Android

Основной способ — установить `AI Flashcard Generator` из каталога Community plugins внутри Obsidian. Для ручной или тестовой установки можно перенести те же три файла файловым менеджером в `<vault>/.obsidian/plugins/ai-flashcard-generator/`, если vault доступен в общей памяти. Включите отображение скрытых папок. Если используете Obsidian Sync, проверьте настройки синхронизации установленных и активных community plugins на обоих устройствах.

Перезапустите Obsidian, включите плагин и выберите API-secret на телефоне. Не рассчитывайте, что секрет автоматически появился после синхронизации обычных настроек.

Откройте заметку в режиме редактирования. Запускайте генерацию через палитру команд, кнопку ленты либо добавьте **Generate flashcards from current note** в мобильную панель инструментов. Для небольшого фрагмента сначала выделите текст. В окне проверьте источник, а в preview — результат. Большие кнопки и закреплённые действия рассчитаны на сенсорный ввод.

## iPhone / iPad

Используется та же сборка. Если приложение Files не даёт удобно работать со скрытой папкой `.obsidian`, перенесите плагин через доступный на компьютере vault/iCloud либо синхронизацию community plugins в Obsidian Sync. Не перемещайте сам vault и не меняйте способ синхронизации ради установки плагина.

Плагин уже доступен в официальном каталоге Community plugins. Ручной перенос нужен только для тестовых сборок или если каталог недоступен.

## Проверка на реальном устройстве перед заявлением полной поддержки

Проверка в браузере уже проведена, но это не тест нативного Obsidian. На каждой платформе нужно записать версию Obsidian/ОС и проверить:

1. Плагин включается; команда и настройки доступны; секрет можно выбрать.
2. Выделение имеет приоритет; иначе передаётся текущий текст редактора.
3. Экранная клавиатура не скрывает активное поле и кнопки; окно прокручивается в портретной и альбомной ориентации.
4. На коротком несекретном тексте проходит реальный Gemini-запрос; ошибки сети и отмена не создают файл.
5. Закрытие preview не создаёт файл; Create сохраняет выбранные пары и отредактированные ответы.
6. Spaced Repetition 1.15.4 видит тег, basic `::` и обе стороны английского `:::`; проверена карточка со `std::move`.
7. Повторное имя получает `(2)`; прежняя колода и `<!--SR:...-->` не изменяются.
8. Блокировка/возврат из фона во время генерации не открывает второй workflow и не сохраняет поздний ответ после отмены.

Запрос, уже переданный Google, может завершиться даже после отмены. Закрытие окна во время уже подтверждённой записи не отменяет атомарный вызов создания файла.

Актуальные инструкции Obsidian: [разработка для мобильных устройств](https://docs.obsidian.md/Plugins/Getting%20started/Mobile%20development), [синхронизация настроек](https://help.obsidian.md/sync/settings).
